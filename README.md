# 익명 서버 랜덤 채팅 디스코드 봇

매일 밤 12시에 참여 설정을 켠 디스코드 서버끼리 1:1로 랜덤 연결하고, 지정된 채널의 메시지를 상대 서버 채널로 익명 전달하는 봇입니다.

## 준비

1. Node.js 20 이상을 설치합니다.
2. Discord Developer Portal에서 봇 애플리케이션을 만들고 토큰과 Client ID를 준비합니다.
3. 이 폴더에서 패키지를 설치합니다.

```powershell
npm install
```

4. `.env.example`을 참고해서 `.env` 파일을 만듭니다.

```env
DISCORD_TOKEN=...
DISCORD_CLIENT_ID=...
BOT_OWNER_ID=...
TEST_GUILD_ID=...
TIMEZONE=Asia/Seoul
CONNECTING_GIF_URL=
```

`TEST_GUILD_ID`를 넣으면 명령어가 해당 서버에 즉시 등록되어 테스트가 쉽습니다. 여러 서버에 넣고 싶으면 `TEST_GUILD_ID=서버ID1,서버ID2,서버ID3`처럼 쉼표로 구분합니다. 빼면 전역 명령어로 등록됩니다.

`CONNECTING_GIF_URL`을 넣으면 연결 시작 안내에 원하는 GIF URL을 표시합니다. 비워두면 프로젝트에 포함된 기본 차원통신 GIF를 사용합니다.

## 실행

```powershell
npm run register
npm start
```

모든 서버에서 명령어를 쓰게 하려면 전역 명령어로 등록합니다. 반영까지 최대 1시간 정도 걸릴 수 있습니다.

```powershell
npm run register-global
```

특정 서버에만 즉시 반영하고 싶으면 서버 ID를 지정해서 등록합니다.

```powershell
npm run register-guild -- 서버ID
```

테스트 서버 명령어와 전역 명령어가 동시에 보여 중복처럼 보이면 테스트 서버 명령어를 지웁니다.

```powershell
npm run clear-guilds
```

전역 명령어를 완전히 지우고 테스트 서버에서만 쓰고 싶으면 전역 명령어를 지웁니다.

```powershell
npm run clear-global
```

## 명령어

봇이 서버에 처음 들어오면 설정 안내 메시지를 보냅니다. 채팅 채널이 설정되기 전에는 `/차원통신 채널설정`, `/차원통신 상태`, `/차원통신 내프로필` 외의 명령어를 사용할 수 없습니다.

- `/차원통신 채널설정 채널`  
  서버 관리자가 익명 채팅 채널을 지정합니다.
- `/차원통신 연결설정 상태`  
  다른 디스코드 서버와 랜덤 연결에 참여할지 설정합니다. 선택지는 `참여`, `중지`입니다.
- `/차원통신 상태`  
  현재 설정과 연결 상태를 확인합니다.
- `/차원통신 내프로필`  
  상대 서버에 표시될 내 서버 프로필을 미리 확인합니다.
- `/차원통신 즉시연결`  
  자정을 기다리지 않고, 현재 연결되지 않은 대기 서버 중 하나를 찾아 이 서버와 연결합니다.
- `/차원통신 한줄메시지설정 메시지`  
  상대 서버에 보여줄 서버 소개 문구를 설정합니다.
- `/차원통신 프로필공개 공개여부`  
  연결 시 서버 사진, 현재 인원, 한줄 메시지를 상대 서버에 공개할지 설정합니다. 선택지는 `공개`, `비공개`입니다.
- `/차원통신 신고 사유`  
  현재 상대 서버를 신고하고 연결을 즉시 종료합니다. 서버마다 하루에 한 번만 사용할 수 있습니다.

## 봇 권한

초대 URL을 만들 때 아래 권한을 포함하세요.

- Send Messages
- Embed Links
- Attach Files
- Read Message History
- View Channels
- Use Slash Commands

메시지 콘텐츠를 읽으려면 Discord Developer Portal에서 **Message Content Intent**도 켜야 합니다.

## 저장 파일

실행 중 `data/store.json`에 서버 설정, 현재 매칭, 신고 기록, 레벨 정보가 저장됩니다.

## 연결 프로필

서버가 연결되면 상대 서버의 프로필이 채팅방에 표시됩니다.

- 서버 이름
- 서버 사진
- 현재 인원
- 한줄 메시지
- 신고 횟수
- 레벨과 경험치

관리자는 `/차원통신 프로필공개`로 이 정보를 숨길 수 있습니다. 비공개 상태에서는 상대 서버에 “프로필 비공개”로만 표시됩니다.

## 레벨

자정 매칭이 실행될 때 기존 연결이 정상 종료되면 양쪽 서버에 경험치 100 XP가 지급됩니다. 경험치가 100 XP 오를 때마다 서버 레벨도 1씩 올라가며, 이 값은 다음 연결부터 상대 서버 프로필에 표시됩니다.

`/차원통신 신고`로 종료된 연결은 정상 종료 보상으로 처리하지 않습니다. 신고 명령어는 `TIMEZONE` 기준 하루 1회만 사용할 수 있습니다.

## 매칭 안내

매일 밤 12시가 되면 활성화된 서버의 지정 채널에 새로운 랜덤 매칭을 시작한다는 안내가 전송됩니다. 연결할 상대 채널을 찾지 못한 서버에는 매칭 실패 안내가 전송됩니다.

## UI 테마

봇 메시지는 차원 통신 장치처럼 보이도록 보라색/청록색 신호 테마의 임베드로 표시됩니다. 서버 연결이 시작되면 `assets/dimension-link.gif`가 먼저 전송되고, 현재 연결 가능한 디스코드 방 수가 함께 표시됩니다. 그 다음 상대 서버 프로필이 도착합니다.
