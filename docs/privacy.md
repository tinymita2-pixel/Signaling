# 익명 서버 채팅 봇 개인정보처리방침

시행일: 2026-07-28

본 개인정보처리방침은 익명 서버 채팅 봇(이하 "봇")이 어떤 정보를 처리하고, 어떻게 사용하며, 얼마나 보관하는지 설명합니다.

## 1. 수집 또는 저장하는 정보

봇은 서비스 제공을 위해 다음 정보를 저장할 수 있습니다.

- 서버 ID
- 서버 이름
- 익명 채팅용 채널 ID
- 서버 프로필 공개 여부
- 서버 한줄 메시지
- 서버 신고 횟수
- 서버 경험치 및 레벨
- 현재 연결된 상대 서버 ID
- 신고 기록: 신고한 서버 ID, 신고된 서버 ID, 신고 사유, 신고 시각

봇은 일반 메시지 내용을 장기 저장하지 않습니다. 다만 메시지는 상대 서버로 전달하기 위해 실시간으로 처리됩니다.

## 2. 정보 사용 목적

수집된 정보는 다음 목적으로 사용됩니다.

- 서버별 익명 채팅 설정 저장
- 서버 간 랜덤 연결 및 메시지 전달
- 서버 프로필 표시
- 신고 기록 관리
- 정상 대화 완료에 따른 경험치 및 레벨 관리
- 오류 확인 및 서비스 안정성 유지

## 3. 정보 공유

봇은 저장된 정보를 판매하지 않습니다. 다만 서비스 기능상 다음 정보는 상대 서버에 표시될 수 있습니다.

- 서버 이름
- 서버 사진
- 현재 인원
- 서버 한줄 메시지
- 서버 신고 횟수
- 서버 레벨 및 경험치

서버 관리자가 프로필을 비공개로 설정하면 위 프로필 정보는 상대 서버에 표시되지 않습니다.

## 4. 보관 기간

서버 설정, 신고 기록, 레벨 정보는 봇 운영에 필요한 동안 보관됩니다. 서버 관리자가 삭제를 요청하거나 봇 운영이 종료되면 합리적인 기간 내에 관련 데이터를 삭제합니다.

## 5. 데이터 삭제 요청

서버 관리자는 자신의 서버와 관련된 저장 데이터 삭제를 요청할 수 있습니다. 삭제 요청은 아래 연락처로 보내주세요.

연락처: 여기에_이메일_또는_디스코드_연락처

## 6. 보안

봇 토큰과 저장 데이터는 외부에 공개하지 않도록 관리합니다. 단, 개인이 운영하는 봇 특성상 완전한 보안을 보장할 수는 없습니다.

## 7. 아동 및 청소년

봇은 Discord가 허용하는 연령의 사용자와 서버를 대상으로 합니다. 사용자는 Discord 이용약관과 각 지역의 관련 법령을 따라야 합니다.

## 8. 변경

본 방침은 봇 기능 변경이나 법적 요구사항에 따라 수정될 수 있습니다. 중요한 변경이 있는 경우 가능한 방식으로 공지합니다.
